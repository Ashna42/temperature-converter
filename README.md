
# Temperature Converter

A simple and interactive temperature conversion application built using HTML, CSS, and JavaScript. It allows users to convert temperature values between Celsius, Fahrenheit, and Kelvin.

## Features

- Convert Celsius to Fahrenheit and Kelvin.
- Convert Fahrenheit to Celsius and Kelvin.
- Convert Kelvin to Celsius and Fahrenheit.
- Simple and user-friendly interface.
- Instant conversion results.
- Responsive design.

## Technologies Used

- HTML5 – Structure
- CSS3 – Styling and layout
- JavaScript – Conversion logic and interactivity

## How to Use

1. Open the Temperature Converter application.
2. Enter the temperature value.
3. Select the input temperature unit.
4. Select the unit you want to convert to.
5. View the converted temperature.
